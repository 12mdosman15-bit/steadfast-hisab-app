1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Railway -> New Project -> Deploy from GitHub Repo.
4. Variables: APP_SECRET=long-random-secret
5. Optional: STEADFAST_BASE_URL=https://portal.packzy.com/api/v1
6. Deploy.
7. Open the app -> Create account -> Settings -> enter your own Steadfast API Key + Secret Key -> Test connection -> Save.
8. Add Parcel -> select English District -> select Thana/Upazila -> Save & Send.
9. Orders will show CN# / Parcel ID and Tracking ID from Steadfast.
